PESOPLAN — THEMES, ALL-REMINDERS MANAGER, AND SAFE RESET UPDATE

WHAT'S NEW
- 50 live color themes, grouped by collection in the theme selector.
- Selecting a theme previews it immediately; Apply theme saves the selection in localStorage.
- The selected theme updates the header, page, cards, forms, controls, buttons, dialogs, and other shared color roles.
- The header logo follows the selected theme number: logos/1.png through logos/50.png. Missing numbered logos fall back to logos/1.png.
- All unpaid reminders now appear in a dedicated manager, including reminders whose personal "Show reminder" window has not started. They can be marked paid or deleted there. Existing repeat schedules and urgent-bill visibility rules remain intact.
- A confirmed full data reset restores default categories and clears tracker records. It uses deletion markers and a newer category timestamp so the reset can sync instead of old cloud records reappearing.

DEPLOY
1. Before deploying, use EUnify's Export backup feature while online.
2. Open https://github.com/digitized-droid/practicemedaddy
3. Replace the four files listed above. Merge the logos folder rather than deleting existing logo files.
4. Commit and push to the branch used by GitHub Pages (usually main).
5. Wait for GitHub Pages to deploy.
6. Open https://digitized-droid.github.io/practicemedaddy/ while online and refresh once.
7. Close and reopen the installed PWA while online if it still shows the previous version. The service-worker cache version has been updated.

IMPORTANT DATA NOTES
- Do not clear browser/site data, uninstall the PWA, or reset the Supabase table as a deployment step.
- Keep the existing Supabase project URL and publishable/anon key. Never put a service-role key in browser code.
- Theme choice is stored locally in this browser using a separate localStorage key and does not modify financial records.
- Offline changes remain in that browser until it reconnects. Cloud sync requires internet and a signed-in account.
- Full tracker reset is destructive. It has a confirmation step and will synchronize its deletion markers when signed in and online. Export a backup first.
- The cloud merge is ID/timestamp based, not a fully atomic multi-device transaction log. Avoid editing the same record on multiple devices at exactly the same time.
