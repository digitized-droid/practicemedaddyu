- Keep the same filename when replacing a placeholder so no HTML changes are needed.

Recommended: use a clear screenshot with no sensitive financial information. The image is scaled to fit the popup while preserving its aspect ratio.

When the website is online, the service worker checks these image files for updates and refreshes its saved offline copies. After replacing an image on GitHub, open the website while connected once so the new visual is downloaded.
